# BW BricsCAD Tools — Installer Downloads

Download point for the **BW BricsCAD Tools** suite, distributed by the Western
Sydney Drafting Department, BW.

## Download

Get the latest installer from the [**Releases**](../../releases/latest) page.
No login is required. The installer only runs on the BW network.

## Documentation

Full documentation for the toolset is at
<https://agabanto.github.io/bw-cad-docs/>.

---

Installers here are published by the suite's release process; do not upload
builds by hand. Installed copies check this repository for updates, so it must
stay public and keep this name.
